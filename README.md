## 💻 Run Locally

Because the portfolio is a self-contained HTML project, no package installation is required.

You can open `index.html` directly in a browser or serve the folder with any simple local web server.

For example, with Python:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## 🎨 Design Direction

The visual direction uses a dark foundation with high-contrast typography, neon-inspired pink, purple, and blue accents, subtle glow effects, generous spacing, and restrained animation.

The goal is to keep the portfolio expressive while maintaining a professional and easy-to-navigate presentation.

## 📝 Content Guidelines
